# Scene change detector

Ноутбук по курсу «Интеллектуальные методы обработки видео»: поиск смен сцен в видео. В нём два задания: детектор на эвристиках (включая плавные переходы) и детектор с моделью из scikit-learn.

- `Scene_change_detector_-_with_dissolve_and_ML.ipynb` — решение
- `model.pkl` — сохранённая модель, ноутбук её загружает
- `Hard_cut[1].jpg` — пример резкой смены сцены

Нужны `numpy`, `opencv-python`, `scikit-learn`, `pandas`, `tqdm`.

Обучающая выборка (около 276 МБ) в репозитории не хранится. Ссылка на неё есть в ноутбуке. Её нужно скачать и положить в папку `train_dataset` рядом с ноутбуком.
